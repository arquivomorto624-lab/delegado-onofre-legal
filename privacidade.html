Política de Privacidade — Delegado Onofre (publicador de vídeos)

Última atualização: 21/11/2026

O aplicativo "Delegado Onofre" é uma ferramenta de uso pessoal, criada e operada pelo próprio dono do canal @delegadoonofre, para enviar vídeos do próprio canal ao YouTube usando a API oficial do YouTube.

Dados acessados. Com a autorização do dono da conta, o app usa apenas a permissão de enviar vídeos ao canal. Ele não lê, não coleta e não armazena dados pessoais de outras pessoas.

Armazenamento. O token de acesso fica somente no computador do dono do canal. Nenhum dado é enviado a servidores de terceiros nem compartilhado, vendido ou usado para publicidade.

Revogação. O acesso pode ser removido a qualquer momento em https://myaccount.google.com/permissions.

Uso dos dados do Google. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Contato. Pelo e-mail de contato exibido na tela de consentimento do app.
